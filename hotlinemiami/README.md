# Hotline Miami (Web HTML5 Port)

Port de Hotline Miami 1 (version Original GameMaker 7) dans le navigateur en HTML5 / WebGL / Web Audio.

🎮 **Jouer en ligne :** [https://mdecombax.github.io/hotline-miami/](https://mdecombax.github.io/hotline-miami/)

---

## 🕹️ Contrôles

| Action | Touche / Contrôle |
|---|---|
| **Déplacement** | `Z Q S D` / `W A S D` / Touches fléchées |
| **Viser / Tourner** | Souris |
| **Attaquer / Tirer** | Clic gauche |
| **Lancer arme / Ramasser / Exécution** | Clic droit / `Espace` |
| **Regarder au loin** | `Shift` (maintenir) |
| **Recommencer** | `R` |
| **Pause** | `Échap` / `P` |

---

## ℹ️ Informations

Ce projet est une conversion technique du jeu original GameMaker 7 vers le runtime GameMaker HTML5 moderne.
- Écran titre, prologue et chapitres 0 à 21 intégrés.
- Rendu pixel-perfect à l'échelle de votre écran.
- Audio Web via Web Audio API.
- Sauvegardes persistantes dans le `localStorage` du navigateur.
